# ESG and stock-return panel for the EAIF group assignment (AS 2026)

Simulated by the course. There are no real firms behind these rows. Licence: CC BY 4.0 (EAIF course,
Bern University of Applied Sciences). The files contain data problems that the assignment asks you to find
and treat; the data dictionary handed out with the assignment describes every column.

| File | Grain | Content |
|---|---|---|
| firm_year_panel.csv | firm x fiscal year | fundamentals, point-in-time ESG scores, environmental metrics, publication date |
| esg_scores_restated.csv | firm x fiscal year | ESG scores as a "current" download would show them |
| stock_returns_monthly.csv | firm x month | total return in percent |
| factors_monthly.csv | month | risk-free rate, market excess return, size and industry factors, percent |
| universe_current.csv | firm | firms in the universe at the end of the last year |
